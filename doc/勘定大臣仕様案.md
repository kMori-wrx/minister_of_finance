# 簡易会計システム 仕様書

## 1. 概要

### 1.1 目的

小規模事業者向けの簡易的な会計管理システムを構築する。

本システムでは、以下の一連の業務を最低限実現する。

```text
取引入力
   ↓
仕訳生成・登録
   ↓
月次集計
   ↓
Excel出力
```

本システムは本格的な会計ソフトの代替ではなく、日々の取引を記録し、月単位で集計・確認できることを目的とする。

---

# 2. 対象機能

| No | 機能      | 概要                | 優先度 |
| -- | ------- | ----------------- | --- |
| 1  | 取引入力    | 日々の入出金・売上・経費等を入力  | 必須  |
| 2  | 仕訳生成    | 取引内容から複式簿記の仕訳を生成  | 必須  |
| 3  | 仕訳確認    | 登録済み仕訳を一覧・検索・確認   | 必須  |
| 4  | 月次集計    | 月単位で勘定科目ごとの金額を集計  | 必須  |
| 5  | Excel出力 | 仕訳・月次集計結果をExcel出力 | 必須  |
| 6  | マスタ管理   | 勘定科目等の基本マスタを管理    | 必須  |
| 7  | データ修正   | 登録済み取引・仕訳を修正      | 必須  |
| 8  | データ削除   | 不要な取引を削除          | 必須  |

# 4. 取引入力

## 4.1 概要

ユーザーが日々発生する取引を入力する。

入力された取引をもとに、システムが複式簿記形式の仕訳を生成する。

---

## 4.2 入力項目

| 項目      | 必須 | 内容           |
| ------- | -- | ------------ |
| 取引日     | ○  | 取引が発生した日     |
| 取引区分    | ○  | 売上、経費、入金、出金等 |
| 金額      | ○  | 取引金額         |
| 支払・入金方法 | ○  | 現金、普通預金、その他  |
| 勘定科目    | ○  | 取引の内容を表す科目   |
| 取引先     | △  | 取引先名         |
| 摘要      | △  | 取引内容の補足      |
| メモ      | △  | システム上のメモ     |

---

## 4.3 取引区分

初期状態では以下を用意する。

| 区分  | 説明          |
| --- | ----------- |
| 売上  | 商品・サービス等の売上 |
| 仕入  | 商品等の仕入      |
| 経費  | 消耗品費、交通費等   |
| 入金  | 売掛金等の入金     |
| 出金  | その他の出金      |
| その他 | 上記以外の取引     |

※必要に応じて取引区分を追加可能とする。

---

## 4.4 入力例

### 例1：消耗品を現金1,000円で購入

```text
取引日       ：2026/09/01
取引区分     ：経費
勘定科目     ：消耗品費
金額         ：1,000円
支払方法     ：現金
摘要         ：事務用品購入
```

生成される仕訳：

```text
借方：消耗品費  1,000円
貸方：現金      1,000円
```

---

### 例2：商品を10,000円売り上げ、現金で受け取った

```text
取引日       ：2026/09/02
取引区分     ：売上
金額         ：10,000円
入金方法     ：現金
摘要         ：商品売上
```

生成される仕訳：

```text
借方：現金      10,000円
貸方：売上      10,000円
```

# 5. 仕訳生成

## 5.1 概要

取引入力された内容をもとに、借方・貸方の仕訳データを生成する。

---

## 5.2 基本ルール

すべての仕訳について、

```text
借方金額 = 貸方金額
```

となることを必須とする。

不一致の場合は登録不可とする。

---

## 5.3 仕訳例

### 経費支払い

```text
取引：
現金で消耗品1,000円を購入

↓

借方
消耗品費　1,000円

貸方
現金　　　1,000円
```

### 売上

```text
取引：
現金で商品10,000円を販売

↓

借方
現金　　　10,000円

貸方
売上　　　10,000円
```

### 銀行入金

```text
取引：
売掛金50,000円が普通預金に入金

↓

借方
普通預金　50,000円

貸方
売掛金　　50,000円
```

# 6. 仕訳一覧

## 6.1 概要

---

## 6.2 表示項目

| ---- | ------------ |
| 仕訳ID | 仕訳を一意に識別するID |
| 取引日  | 取引日          |
| 借方科目 | 借方勘定科目       |
| 借方金額 | 借方金額         |
| 貸方科目 | 貸方勘定科目       |
| 貸方金額 | 貸方金額         |
| 取引先  | 取引先          |
| 摘要   | 取引内容         |
| 登録日時 | 登録日時         |

---

## 6.3 検索条件

以下の条件で検索できるようにする。

* 期間
* 勘定科目
* 取引先
* 取引区分
* 金額
* 摘要

---

## 6.4 並び順

初期表示は、

```text
取引日 DESC
仕訳ID DESC
```

とする。

新しい仕訳を上に表示する。

# 7. 仕訳修正

## 7.1 概要

登録済みの取引・仕訳を修正できる。

---

## 7.2 修正可能項目

* 取引日
* 取引区分
* 金額
* 借方科目
* 貸方科目
* 支払・入金方法
* 取引先
* 摘要
* メモ

---

## 7.3 修正時の処理

仕訳を直接変更するのではなく、原則として元となる取引データを変更する。

```text
取引データ変更
      ↓
仕訳再生成
      ↓
仕訳更新
```

これにより、取引内容と仕訳内容の不整合を防止する。

---

# 8. 仕訳削除

## 8.1 概要

誤って登録した取引を削除する。

---

## 8.2 削除方式

基本的には物理削除ではなく、論理削除を推奨する。

```text
is_deleted = true
```

削除済みデータは通常の一覧には表示しない。

---

# 9. 月次集計

## 9.1 概要

登録された仕訳を月単位で集計する。

---

## 9.2 集計単位

```text
年
 ↓
月
 ↓
勘定科目
```

---

## 9.3 集計項目

最低限、以下を集計する。

| 項目   | 内容        |
| ---- | --------- |
| 勘定科目 | 勘定科目名     |
| 借方合計 | 月内の借方合計   |
| 貸方合計 | 月内の貸方合計   |
| 差額   | 借方合計－貸方合計 |

---

## 9.4 集計例

2026年9月の場合：

```text
勘定科目       借方        貸方
--------------------------------
現金           50,000      30,000
普通預金       100,000     50,000
売上           0           150,000
消耗品費       10,000      0
通信費         5,000       0
--------------------------------
合計           165,000     230,000
```

※実際の会計帳簿として成立するかどうかは、入力された仕訳内容による。

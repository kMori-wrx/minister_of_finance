# 簡易会計システム HTMLモック実装計画

仕様案に基づき、**勘定奉行風のUI**で操作感を評価できるHTMLモックを作成します。

## デザインコンセプト：勘定奉行風UI

勘定奉行の特徴的なUI要素を再現します。

- **左側サイドバーメニュー**：ツリー形式のナビゲーション（アイコン付き）
- **上部ヘッダー**：会社名・年度・ユーザー情報表示バー
- **業務ツールバー**：画面上部に配置された操作ボタン群（新規・保存・削除・印刷等）
- **グリッド形式テーブル**：Excel風の入力グリッド（罫線付き、交互行色分け）
- **カラーパレット**：ダークブルー系のヘッダー、白背景のコンテンツ、グレー系のツールバー
- **ステータスバー**：画面下部にレコード件数・日付等を表示
- **モーダルダイアログ**：確認メッセージ・マスタ選択用ポップアップ

## 実装画面一覧（7画面 + 共通部品）

### 共通レイアウト
- ヘッダーバー（ロゴ・システム名・会社名・年度・ユーザー名）
- サイドバーメニュー（ツリー構造のナビゲーション）
- ステータスバー（画面下部）
- 共通CSS（勘定奉行風デザインシステム）

---

### 画面1: ダッシュボード
- 当月の売上・経費サマリーカード
- 取引件数の表示
- 直近の取引一覧（5件程度）
- クイックアクセスボタン（取引入力・仕訳一覧・月次集計・Excel出力）

### 画面2: 取引入力
- 入力フォーム（取引日・取引区分・金額・支払方法・勘定科目・取引先・摘要・メモ）
- 仕訳プレビュー（入力内容に連動して借方/貸方をリアルタイム表示）
- ツールバー（新規・保存・クリア）
- バリデーションエラー表示

### 画面3: 取引一覧（仕訳一覧兼用）
- 検索条件パネル（期間・勘定科目・取引先・取引区分・金額・摘要）
- データグリッド（仕訳ID・取引日・借方科目・借方金額・貸方科目・貸方金額・取引先・摘要）
- ツールバー（編集・削除・Excel出力）
- ページング

### 画面4: 取引編集（モーダルまたは別画面）
- 取引入力と同様のフォーム（既存データ読み込み済）
- 仕訳プレビュー更新

### 画面5: 月次集計
- 年月選択（ドロップダウン）
- 集計テーブル（勘定科目・借方合計・貸方合計・差額）
- 合計行
- Excel出力ボタン

### 画面6: 勘定科目マスタ
- 科目一覧グリッド（科目コード・科目名・区分・表示順・有効フラグ）
- 新規追加・編集・無効化ボタン
- 科目区分別タブまたはフィルタ（資産・負債・収益・費用）

### 画面7: Excel出力
- 出力対象選択（仕訳一覧 / 月次集計）
- 対象期間指定
- プレビュー表示
- 出力ボタン

## 技術実装

### ファイル構成

#### [NEW] `index.html`
メインのHTMLファイル。全7画面を含むSPA（Single Page Application）構成。

#### [NEW] `style.css`
勘定奉行風のデザインシステム。ダークブルー系ヘッダー、グリッドスタイル、ツールバー等。

#### [NEW] `app.js`
画面遷移ロジック、サンプルデータ管理、フォーム操作、バリデーション等。

### サンプルデータ
モックとして操作感を評価するため、以下のサンプルデータを事前登録します。
- 勘定科目マスタ：仕様書の初期科目16科目
- 取引データ：10件程度のサンプル取引
- 仕訳データ：取引に紐づく仕訳10件程度

## 操作フロー

モックで確認できる操作フローは以下の通りです。

1. **ダッシュボード** → 当月サマリー確認 → クイックアクセスボタンで各画面へ遷移
2. **取引入力** → フォーム入力 → 仕訳プレビュー確認 → 保存（サンプルデータに追加）
3. **取引一覧** → 検索条件で絞り込み → 行選択 → 編集画面へ遷移
4. **取引編集** → フォーム修正 → 保存
5. **月次集計** → 年月選択 → 集計実行 → 結果確認
6. **勘定科目マスタ** → 科目一覧確認 → 新規追加・編集
7. **Excel出力** → 出力対象・期間選択 → プレビュー確認 → 出力（CSVダウンロード）

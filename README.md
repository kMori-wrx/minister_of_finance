# 勘定大臣 - 簡易会計システム

小規模事業者向けの簡易会計管理システムです。取引の入力から仕訳生成・月次集計・Excel出力までの一連の会計業務をブラウザ上で完結できるSPA（Single Page Application）です。

---

## 概要

日々発生する取引を入力するだけで、複式簿記の仕訳を自動生成し、月次集計や帳票出力まで行える軽量な会計ツールです。  
本格的な会計ソフトの代替ではなく、**日々の取引を手軽に記録・集計・確認することを目的**としています。

---

## 主な機能

| 機能 | 概要 |
|---|---|
| ダッシュボード | 当月の売上・経費サマリー、直近取引の一覧表示 |
| 取引入力 | 日々の入出金・売上・経費等を入力、仕訳をリアルタイムプレビュー |
| 取引・仕訳一覧 | 登録済み仕訳の検索・一覧表示・編集・削除 |
| 月次集計 | 勘定科目ごとに借方・貸方を月単位で集計 |
| Excel出力 | 仕訳一覧・月次集計をCSV/Excel形式でダウンロード |
| 勘定科目マスタ | 科目の登録・編集・有効化/無効化 |

---

## 使い方

特別なインストールは不要です。ブラウザで `index.html` を開くだけで動作します。

```
勘定大臣/
├── index.html   # メインHTML（全7画面のSPA）
├── style.css    # スタイルシート（勘定奉行風UIデザイン）
├── app.js       # 画面ロジック・サンプルデータ・バリデーション
└── doc/         # 設計ドキュメント
    ├── 勘定大臣仕様案.md
    └── モックデザイン案.md
```

---

## デザインコンセプト

勘定奉行風のUIを採用しています。

- **ダークブルー系ヘッダー**と白背景のコンテンツ
- **左サイドバーメニュー**によるナビゲーション
- **グリッド形式テーブル**（Excel風の罫線・交互行色分け）
- **ツールバー**（新規・保存・削除・印刷等）
- **モーダルダイアログ**による確認・マスタ選択

## 注意事項

- 本システムは**モック（プロトタイプ）**です。データはブラウザのメモリ上にのみ保存されます。
- ページを再読み込みするとサンプルデータの状態に戻ります。
- 本格的な運用には、バックエンド・DBの実装が別途必要です。
